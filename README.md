# 🌍 RELTO – Community Lost & Found Platform

> **RELTO** is a community-driven **lost & found platform** with an interactive map experience.  
> Report found items, locate lost belongings nearby, and earn rewards for helping reunite items with their owners. 💙

## 🗺️ Interactive Map Features

- **Mapbox GL** powered live map
- Real-time item markers
- Nearby item discovery using geolocation
- Smooth **fly-to animations** on selection
- Distance routes drawn between user & item

---

## 📦 Item Management

- Post **found items** with:
  - Photos 📷
  - Descriptions 📝
  - Exact map locations 📍
- **16+ item categories** with urgency levels:
  - Wallet, Phone, Keys, Pets (Dog/Cat), Bags
  - Documents, Watch, Glasses, Headphones
  - Camera, Books, Cards, Jewelry & more
- Secure **claim system**
- Automatic item expiration
- Radius-based location privacy

## 🎮 Gamification System

### 🏆 Points
| Action | Points |
|------|-------|
| Post Item | +50 |
| Claim Item | +100 |
| Confirm Return | +200 |

### 🧭 Levels
| Rank | Points Required |
|----|---------------|
| Beginner | 0 – 1999 |
| Helper | 2000 – 4499 |
| Expert | 4500 – 7499 |
| Master | 7500 – 9999 |
| Legend | 10000+ |

### 🎖️ Achievements
- First Post
- Good Samaritan
- Lucky Finder
- Community Hero *(coming soon)*
